Original producer files remain unchanged; the output manifest records their SHA-256 and the converted files' SHA-256. Example after independently generating outputs:

```bash
python scripts/normalize_manuscript_results.py --tables 04 05 06 12 \
  --out-dir outputs/observed_subset_01
python scripts/compare_manuscript_results.py --tables 04 05 06 12 \
  --observed-dir outputs/observed_subset_01
```

For all tables specify both explicit source paths for Tables 21 and 22; other paths can also be overridden. Do not select a run merely because its values resemble the reference. Table 06 is calculated from paired seeds; 11 uses only energy-normalized percentiles; 20 averages per-ratio timing ratios as specified in the caption; 21 maps the four stress scenario slugs and derives signed gains. The adapter checks available counts and unique row keys, but cannot independently certify seed identities in pre-aggregated outputs, input identities, configuration, measurement draws or historical profiles. Verify those separately. Table 20 timing remains informational. Missing producers are NOT_RUN; invalid tables are FAIL; either produces nonzero exit status. Valid tables may still be compared individually. No field results were generated by this change.

## Functional validation (05d.2b)

Run `python scripts/test_manuscript_adapters.py`. Independent artificial producer fixtures cover Tables 04–24, check expected numeric transformations, and require the comparator to reject the artificial results as manuscript reproduction. Negative cases include missing/duplicate rows, missing columns, nonfinite metrics, invalid counts where applicable, and unexpected F03 compact-table ratios. The CLI checks complete normalization, absent producer classification, reference directory rejection and nonempty destination rejection. Results are saved to outputs/validation/adapter_fixtures.json. The technical workflow runs this suite; approval requires an actual successful execution. These fixtures do not establish the validity of historical run selection or field data.
