# Step-32 development split sensitivity (Appendix B.8)
Run `bash scripts/run_r1m03_step32_dev_splits.sh`. Ten random_per_well development splits (split seeds 0 through 9); validation fraction 0.10; model/measurement seed 7 fixed. Window length 64, step 32, nominal ratios 0.05,0.10,0.20, synthetic noise standard deviation 0.01. Development wells F02-1,F03-2,F06-1, held-out F03-4; target Vc and channels sonic,rhob,ai,vp. No boundary embargo in this experiment. Report paired full-window RMSE across splits, not across new geological realizations. Output: outputs/reviewer_revision/r1m03_step32_dev_splits/ and outputs/paper_assets/tables/. Use the default N_SPLITS=10 for the manuscript.
